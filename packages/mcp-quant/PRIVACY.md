# 隐私政策 — @keelcodes/mcp-quant

最后更新：2026-11-02

本包是一个本地运行的 MCP server。它把 K 线、行情、因子、预测与交易日历查询转发到
Keel API（默认 `https://keel.codes`），并把结果返回给 MCP 客户端。

## 我们收集什么

- **调用计数**：按 API key / owner / 模块统计请求次数与额度使用量，用于计量与免费额度重置。
- **错误码**：如 HTTP 状态码、契约错误码（例如 `429`、`INVALID_INPUT`），用于排障与可用性监控。

## 我们不收集什么

- 不收集、不上传任何**对话内容**或 prompt 文本。
- 不落库请求参数（如交易符号、时间窗、模型选择）作为用户画像或分析数据。
- 不收集本机文件、环境变量、私钥或助记词。
- 不做跨站跟踪，不投放广告。

## 凭据与网络

- `KEEL_API_KEY` 仅保存在你本机环境变量 / MCP 客户端配置中，由本包直接发送给 Keel API。
- 本包不含任何平台级凭据；除 `KEEL_API_BASE` 指向的地址外不会向其它服务发送请求。
- 除行情与量化数据源外，不向第三方共享你的调用信息。

## 数据保留

计量计数按账期保留，用于额度结算与对账；错误码聚合后保留用于服务稳定性分析。
